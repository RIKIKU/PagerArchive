TOPIC
    about_PagerArchive

SHORT DESCRIPTION
    Manage a PagerArchive server from PowerShell: sign in, manage templates
    and aliases, import aliases through the pipeline, search messages, and
    back up the server now.

LONG DESCRIPTION
    The PagerArchive module uses PagerArchive's API, the same one the
    browser uses, so the same rules apply and alias changes are recorded in
    each alias's history as yours. PowerShell access is for admins.

    Every command has a short alias with Pa in place of PagerArchive, e.g.
    Get-PaAlias for Get-PagerArchiveAlias.

  SIGNING IN
    Connect-PagerArchive -Uri https://pager.example.org

    Opens your browser at PagerArchive's normal sign-in (email and
    password). When you've signed in, the browser says you can close it.
    There are no API keys: the module signs in as you, with PKCE and a
    redirect to a port on your own machine (127.0.0.1).

    On a machine with no browser:

        Connect-PagerArchive -Uri https://pager.example.org -UseDeviceCode

    shows a code to enter at Authentik's /device page on any device.

    A tool connects as a read-only service account, made on the server
    with pagerarchive service-account create, without a browser:

        Connect-PagerArchive -Uri https://pager.example.org -ServiceAccount (Get-Credential -UserName report-bot)

    Paste its credential as the password. It reads what an admin reads,
    except people's details, and changes nothing.

    The module renews its access automatically, and the sign-in is saved so
    new PowerShell windows use it:

    - Windows: a file in %LOCALAPPDATA%\PagerArchive\SignIns, with the
      sign-in encrypted by Windows' data protection (DPAPI). Only your
      Windows account on that machine can read it. Nothing needs installing.
    - Linux and macOS: your default SecretManagement vault. With no vault
      registered, the sign-in lasts for that session only, and a warning
      says how to set one up:

        Install-PSResource -Name Microsoft.PowerShell.SecretManagement, Microsoft.PowerShell.SecretStore
        Register-SecretVault -Name SecretStore -ModuleName Microsoft.PowerShell.SecretStore -DefaultVault

      SecretStore asks for its password when first used and again after
      15 minutes; Set-SecretStoreConfiguration -PasswordTimeout changes
      that. Unlock it with Unlock-SecretStore.
    - Anywhere: Connect-PagerArchive -Vault <name> uses that vault.

    A sign-in that isn't used for 30 days ends. Disconnect-PagerArchive
    revokes it and deletes the saved copy. Deactivating, deleting or
    demoting someone in PagerArchive takes effect on their next command.

    A test copy on your own network over plain HTTP needs
    -AllowUnencryptedAuthentication, and warns each time, because the
    sign-in is sent unencrypted.

  OBJECTS
    PagerArchive.Template     Name, Agency, Colour, AgencyProfile, HasIcon,
                              AliasCount
    PagerArchive.Alias        Pattern, Name, Template, Colour, Ignored
    PagerArchive.ImportResult Index, Result, Pattern, Name, Changes,
                              SquashedInto, Applied
    PagerArchive.Message      SentAt, Capcode, Alias, Agency, Priority, Text,
                              and everything the detail view shows
    PagerArchive.Connection   Uri, Name, Email, Role, SavedIn, ExpiresAt
    PagerArchive.Backup       State, Run, LastGoodAt, LastRunAt, Nights,
                              Error, and the last good backup's size and times
    PagerArchive.Reparse      State, Done, Total, Percent, PerMinute,
                              TimeLeft, StartedAt, and its reasons as codes
    PagerArchive.Redaction    State, Done, Total, Percent, Redacted,
                              PerMinute, TimeLeft, StartedAt, and its reason

    An alias's properties are the import's parameters, so

        Get-PagerArchiveAlias | Export-Csv -Path aliases.csv

    writes the import format, and importing that file changes nothing.

  IMPORTING ALIASES
        Import-Csv -Path aliases.csv | Import-PagerArchiveAlias -AgencyProfile @{ 'Example Fire' = 'example-fire' }

    The rows are one batch. New capcodes are added; existing aliases are
    left alone and their differences reported, unless -Update. Rows for one
    capcode that differ stop the whole import and are listed as errors, and
    so do rows giving a name another alias or row has (alias names are
    unique, ignoring letter case). Leave rows out in the pipeline and
    import again:

        Import-Csv -Path aliases.csv | Where-Object -FilterScript { $_.id -ne '10' } | Import-PagerArchiveAlias

    -WhatIf is the dry run. It asks nothing, changes nothing, and outputs
    every row's result with Applied $false:

        Import-Csv -Path aliases.csv | Import-PagerArchiveAlias -WhatIf |
            Where-Object -Property Result -EQ 'Different'

  COMMON PIPELINES
    Messages to a group of aliases in the last week:

        Get-PagerArchiveAlias -Name 'Station*' |
            Get-PagerArchiveMessage -After (Get-Date).AddDays(-7)

    Emergency messages from one capcode, to a spreadsheet:

        Get-PagerArchiveMessage -Capcode 0100001 -Priority Emergency |
            Select-Object -Property SentAt, Alias, Text |
            Export-PagerArchiveCsv -Path station1.csv

    Export-PagerArchiveCsv works as Export-Csv, but writes a value that
    starts with =, +, -, @, a tab or a carriage return with a leading
    apostrophe, so a page sent to look like a formula never runs as one in
    a spreadsheet. Use it for messages, rather than Export-Csv.

    New Emergency pages as they arrive, until Ctrl+C (a lost connection is
    retried, and what arrived meanwhile comes out once it's back):

        Watch-PagerArchiveMessage -Priority Emergency |
            ForEach-Object -Process { "$($_.Alias): $($_.Text)" }

    Capcodes with no alias, busiest first:

        Get-PagerArchiveMessage -Unaliased -After (Get-Date).AddDays(-30) |
            Group-Object -Property Capcode | Sort-Object -Property Count -Descending

    Give a template an icon from a file or a web address. A web address
    is downloaded on this computer (at most 100 KB, within 30 seconds)
    and the file uploaded; PagerArchive never fetches it itself:

        Set-PagerArchiveTemplate -Name 'Example Fire' -Path ./fire.png
        Set-PagerArchiveTemplate -Name 'Example Fire' -Uri 'https://example.test/fire.png'
        Set-PagerArchiveTemplate -Name 'Example Fire' -RemoveIcon

    Rename a template; its aliases keep it and show the new name:

        Rename-PagerArchiveTemplate -Name 'Example Fire' -NewName 'Example Fire North'

    Move aliases to another template, checking first:

        Get-PagerArchiveAlias -Template 'Old Fire' |
            Set-PagerArchiveAlias -Template 'Example Fire' -WhatIf

    Rename several aliases at once: -NewName takes a script block that
    works out each one's new name from the alias ($_). Set- doesn't
    rename, and with nothing to change it's an error (nothing_to_change):

        Get-PagerArchiveAlias -Name 'Old *' |
            Rename-PagerArchiveAlias -NewName { $_.Name -replace '^Old\s+' } -WhatIf

  TAB COMPLETION
    Tab completes template names (-Template, and -Name on the template
    commands), agencies (-Agency), agency profiles (-AgencyProfile) and
    event categories (-Category) from the server you're connected to.
    Alias names, call signs, capcodes and job numbers aren't completed:
    there are too many. Each list is kept for 5 minutes in this session;
    when what you've typed matches nothing in it, the server is asked once
    more, so a template added a moment ago shows up. Values with spaces are
    quoted. Not connected in this session, or the server can't be reached:
    Tab offers nothing, and shows no error.

  BACKING UP NOW
    The server backs up both databases each night, and checks each backup.
    Before a change you might want to undo, such as an upgrade, back up now:

        Start-PagerArchiveBackup -Wait

    The server's backup service starts it within a minute, then dumps and
    checks, as for the nightly backup. -Wait waits until it's done (30
    minutes at most, or -Timeout) and writes an error if it failed. Without
    -Wait, the command returns at once; Get-PagerArchiveBackup shows how
    it's going. One at a time: while one is asked for or running, another
    is refused (backup_queued, backup_running).

  RE-PARSING
    After an alias, template or profile change, the server re-parses the
    stored messages it affects in the background; a profile change
    re-parses the whole archive. A restart or upgrade carries it on from
    where it got to. To see how it is going:

        Get-PagerArchiveReparse

    Suspend-PagerArchiveReparse pauses it after the message in hand, even
    across a restart, and Resume-PagerArchiveReparse carries it on.
    Stop-PagerArchiveReparse cancels it: the messages it did stay re-parsed,
    the rest stay as they were. Start-PagerArchiveReparse runs it again from
    the beginning. A change its state doesn't allow is refused
    (reparse_not_running, reparse_not_paused, reparse_stopped, reparse_none).

  RETROACTIVE REDACTION
    When the redaction rules change, the nightly run checks every stored
    message against them, writing each changed message's new text and its
    re-parse together. A restart or upgrade carries it on from where it got
    to. To see how it is going:

        Get-PagerArchiveRedaction

    Suspend-PagerArchiveRedaction pauses it, even across a restart and the
    nightly run, and Resume-PagerArchiveRedaction carries it on.
    Stop-PagerArchiveRedaction cancels it: the messages it did stay done,
    and the next nightly run starts it again from the beginning.
    Start-PagerArchiveRedaction runs it again from the beginning now. A
    change its state doesn't allow is refused (redaction_not_running,
    redaction_not_paused, redaction_stopped).

  ERRORS
    A refusal from PagerArchive is an error whose ErrorId is the API's
    code (e.g. duplicate_alias, template_in_use, powershell_admins_only)
    and whose message is the API's. A failure on one item doesn't stop the
    rest of the pipeline; not being signed in, or the server being
    unreachable, does.
